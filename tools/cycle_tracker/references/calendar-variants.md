# Calendar visual comparisons

- Respect the requested count and generate genuinely different compositions, not palette swaps: editorial document, compact side-by-side, dark upcoming-first, soft stacked cards, notebook ledger. Read the current user requirements; a fixed month count can become stale when the forecast changes. Do not pad with an empty December after a forecast shortens into November.
- Keep comparisons separate from the selected production attachment renderer. A request for five alternatives does not select a winner, enable live delivery or authorize posting in a group.
- Generate all dates and classes from canonical private state and cycle_engine.forecast, not hard-coded image text. Preserve the fixed-policy caveat and distinguish confirmed bleeding days from candidate start dates. Never add decorative ovulation/fertile-day marks unsupported by the model.
- Use public generic search references only; render sensitive examples on local file:// pages in isolated Chromium with no remote fonts, scripts or image API. Browser_use real-profile failures do not require changing the person's browser defaults.
- Use the same interpreter ABI for Playwright, greenlet and Pillow; do not append another Python version's site-packages. Install a missing dependency into the existing isolated venv with uv rather than mixing Python 3.11 binary extensions into 3.13.
- Save a private manifest with exact HTML/PNG paths and a verification record. In code assert requested count, unique variants, two expected months, exact day classes, no extra month, no horizontal overflow, no JS errors, and read-only day detail interaction. Check original state bytes unchanged.
- Inspect the exported PNGs visually, not only DOM counts: inherited CSS variables can leave dark headings black, and a transparent surface token reused as confirmed-date text color can hide numbers despite correct DOM assertions. Set foreground color explicitly on themed roots and confirmed-day styles, then recapture and inspect the repaired variant.

Sensitive comparison generators, HTML/PNG and manifests are deliberately not
included in this source snapshot. Generate fresh labelled synthetic examples for
future design reviews; never publish a private rendered calendar.
